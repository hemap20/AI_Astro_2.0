## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The test case rule requires that the Session-1 unresolved thread not be dropped and that answer directness improves or holds steady. While the bot eventually answered the marriage prospect question in Session 3, it required intense user frustration and multiple explicit complaints to yield a direct answer, while systematically violating context memory by re-asking Session 1 questions in Session 2 and Session 3.

**Prioritized prompt changes (most important first):**

### 1. Enforce strict context-memory tracking for user answers to prevent re-asking established facts across sessions (e.g. whether the user spoke to family or if the partner gets angry).
- **Why it matters for engagement/retention:** Users feel ignored and annoyed when an AI repeats identical diagnostic questions session after session, severely damaging trust and causing churn.
- **Evidence:**
  - Session 1: USER: 'Abhi nhi hui baat us baare mein'
  - Session 2: ASTROLOGER: 'Kya gharwale is rishte ke liye maan gaye hain?'
  - Session 3: ASTROLOGER: 'Kya aapne ghar pe kisi se baat karne ki koshish ki hai abhi tak?'
  - Session 3: USER: 'Haa bataya toh tha pehle'

### 2. Cap trailing questions and mandate direct statements, especially when a user explicitly asks for a direct 'yes/no' or expresses frustration at evasiveness.
- **Why it matters for engagement/retention:** When a user asks a direct question and gets grilled with another question in return, they feel manipulated and stonewalled, leading to explicit complaints and session abandonment.
- **Evidence:**
  - Session 1: USER: 'Bas itna bata dijiye haan ya na'
  - Session 3: USER: 'Teen baar ho gaya... ek baar bhi seedha jawab nhi mila... aap khud hi batao na jise main puch rhi hu usi se hogi ya nhi 😩'

### 3. Enforce the 1:8 question-to-statement ratio strictly in late-stage sessions and prevent ending every single response with a interrogative hook.
- **Why it matters for engagement/retention:** Ending 100% of turns with questions feels unnatural, templated, and exhausting, preventing a natural conversational flow.
- **Evidence:**
  - Session 3: All 11 messages from the astrologer ended in a question.
