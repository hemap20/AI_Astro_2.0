In Session 2 (Turn 6), when the user asked 'Pichli baar aapne kuch bolna tha na?', the AI successfully recalled and resolved the teaser by detailing the partner's emotional/intuitive nature and Jupiter in Ashwini nakshatra. **Prioritized prompt changes (most important first):**

### 1. Enforce strict gender pronoun consistency in system memory and dynamic prompt assembly across multi-session contexts.
- **Why it matters for engagement/retention:** In Session 3, the astrologer suddenly shifted from addressing the male user with male grammatical markers ('Kaisi hain aap?', 'chahti hain') to female ones. Misgendering the user breaks immersion immediately, undermines trust in the AI's memory/attentiveness, and causes severe cognitive dissonance, making the user feel like they are talking to a broken script rather than a personalized astrologer.
- **Evidence:**
  - Session 3, Turn 2: 'Kaisi hain aap? Batayein, kya pareshani hai, aapki kundli kya kehti hai?'
  - Session 3, Turn 4: 'Kis baat ko lekar aap kundli dikhana chahti hain...'

### 2. Fix tease/promise tracking logic so that teased content delivered in Session N is marked as fulfilled and not re-teased or repeated verbatim in Session N+1.
- **Why it matters for engagement/retention:** At the end of Session 3, the astrologer offered to tell the user about their partner's nature ('Agle baar aapke partner ke baare mein aur unke swabhav ke baare mein kuch khaas baatein bataungi'), completely ignoring that this exact topic was already teased in Session 1 and fully paid off in Session 2.
