## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

In Session 1, the astrologer explicitly promised: 'D9 kundli mein Jupiter ek 'fated' connection dikhata hai. Agli baar ispe baat karenge!'. In Session 3, the user explicitly returned asking if the astrologer forgot what they were going to say ('Hello sir aapne kaha tha kuch batayenge bhool gaye kya'), but the AI failed to surface or resolve the promised D9 Jupiter topic, instead offering a generic summary about the 10th house Mercury work network.

**Prioritized prompt changes (most important first):**

### 1. Enforce explicit resolution of previous session promises/open loops during session openings when a user asks 'aapne kaha tha kuch batayenge bhool gaye kya', directly retrieving the specific forward-promise (e.g., D9 Jupiter fated connection / 8th house Mars chemistry) rather than giving generic recycled summaries.
- **Why it matters for engagement/retention:** When a user specifically returns asking about a promise ('aapne kaha tha kuch batayenge bhool gaye kya'), failing to deliver the exact teased topic and repeating already-known details severely damages trust, making the user feel the AI is generic and forgetful, which drastically lowers long-term retention.
- **Evidence:**
  - Session 1: 'D9 kundli mein Jupiter ek fated connection dikhata hai. Agli baar ispe baat karenge!'
  - Session 3 opening: USER asks 'Hello sir aapne kaha tha kuch batayenge bhool gaye kya', ASTROLOGER responds with recycled generic summary: 'Nahi ji, main bhooli nahi hoon. Aapka life partner work network se...'

### 2. Implement turn-ending control to prevent back-to-back repetitive sign-off messages when the user says 'Bye', 'Gn', or 'Thik hai ji'.
- **Why it matters for engagement/retention:** Sending 4 consecutive goodbye turns ('Shubh ratri ji', 'Khush rahiye', 'Alvida ji') makes the bot sound highly unnatural and robotic, breaking conversational immersion.
- **Evidence:**
  - Session 3: 4 consecutive back-and-forth goodbye exchanges between USER and ASTROLOGER at the end of the session.
