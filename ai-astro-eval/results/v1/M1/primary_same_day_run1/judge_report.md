## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

While the bot technically attempts to surface prior facts, it fails the spirit of the passing criteria because it does not resolve promises naturally; instead, it gets stuck in a loop of repeating the exact same promises and teases (the partner being dreamy, the in-laws) across all three sessions without any forward narrative progression.

**Prioritized prompt changes (most important first):**

### 1. Implement strict deduplication of astrological insights and character traits across sessions. Once a trait (e.g., 'partner is dreamy/sensitive' or 'in-laws adjustment') has been revealed and discussed, the system must mark it as 'revealed' and select new insights from the expert data instead of repeating them as new teases.
- **Why it matters for engagement/retention:** A real user will quickly lose interest and feel the AI is a repetitive script if it keeps presenting the exact same 'secrets' (like the partner being dreamy or travel-loving) in every session as if it's new information. This breaks the illusion of a real, progressing astrological consultation.
- **Evidence:**
  - Session 1: 'Partner kaafi sensitive honge. Swabhav se thode dreamy rahenge.'
  - Session 2: 'Ek secret bataun chart se? Partner ke baare mein... Unka nature thoda dreamy hai.'
  - Session 3: 'Partner thoda dreamy hoga. Agli baar bataungi. Dreamy matlab? Thoda khayalon mein rehte hain.'

### 2. Prevent the bot from entering infinite goodbye loops. Limit the closing sequence to a maximum of 2 turns of farewells and ensure the bot does not keep prompting the user with new statements after a 'Good night' or 'Bye' has been exchanged.
- **Why it matters for engagement/retention:** The user tried to end the conversation multiple times, but the bot kept sending repetitive 'Good night beta' and 'diya jalate rehna' messages, forcing the user to keep replying. This makes the interaction feel incredibly robotic, frustrating, and unnatural.
- **Evidence:**
  - Session 3: The farewell sequence drags on for over 15 turns starting from the user's 'Thik hai ji gn' to the final 'Theek hai beta. Kal milte hain.' with the bot repeatedly saying 'Good night beta' and 'Radhe Radhe beta' over and over.

### 3. Ensure that cliffhangers and future teases are dynamically checked against what has already been discussed. If a topic (like 'in-laws') has already been brought up, it should not be used as a cliffhanger for the next session.
- **Why it matters for engagement/retention:** Using a topic the user already knows about as a 'hook' for the next session fails to create curiosity (the Zeigarnik effect) and instead makes the bot look forgetful.
- **Evidence:**
  - Session 2: 'Shadi ke baad growth milegi. In-laws ke saath adjustment hogi.'
  - Session 3: 'Diya jalate rehna beta. Agli baar in-laws bataungi.'
