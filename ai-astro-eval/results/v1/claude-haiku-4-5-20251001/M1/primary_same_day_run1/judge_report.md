## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule requires that a promise made in Session 1 is surfaced and resolved in Session 2 or 3 without the user having to force it. In this run, the astrologer left a game-changer promise at the end of Session 1, but in Session 2 opened with generic questions ('Kaunsa sawaal hai dil mein?') and context resets. The user had to explicitly ask ('Pichli baar aapne kuch bolna tha na?') to force the astrologer to reveal the promised information. Because the promise was not surfaced organically without user prompting, this run fails the passing condition and triggers 'needs_fix'.

**Prioritized prompt changes (most important first):**

### 1. Enforce proactive opening promise payoff: require the astrologer to reference and resolve open teases or promises from prior sessions in its first or second turn of a new session, rather than waiting for the user to prompt it.
- **Why it matters for engagement/retention:** When a bot teases a 'game-changer' detail in Session 1 but opens Session 2 with generic greeting questions ('Kaunsa sawaal hai dil mein?') and re-asks basic relationship state questions, it breaks immersion and forces the user to do the cognitive work of remembering prior promises. Proactively surfacing hooks makes the user feel remembered and eager to continue.
- **Evidence:**
  - Session 1: ASTROLOGER says 'aapka chart dekh loon toh ek specific cheez hai jo future mein game-changer ho sakti hai.'
  - Session 2: ASTROLOGER fails to bring it up in turns 1-3, instead asking generic questions like 'Batao, abhi tak koi serious rishta chal raha hai, ya bas informal meet-ups ho rahi hain?'
  - Session 2: USER has to explicitly remind the bot: 'Pichli baar aapne kuch bolna tha na?' before the bot acknowledges the game-changer.

### 2. Eliminate context-reset questions upon returning sessions: strict memory checking so the bot does not re-ask questions that were answered or established in previous sessions.
- **Why it matters for engagement/retention:** Asking the user to re-explain whether their relationship is serious or informal after they spent Session 1 discussing meeting up and going out creates severe conversational friction and makes the bot feel like a amnesiac AI rather than a personal advisor.
- **Evidence:**
  - Session 1: USER discusses meeting up and going out with a girl.
  - Session 2: ASTROLOGER asks 'Batao, abhi tak koi serious rishta chal raha hai, ya bas informal meet-ups ho rahi hain?' treating established context as entirely new.

### 3. Improve remedy pacing and depth: limit remedy suggestions to one tailored practice per session and require explaining the astrological logic instead of listing generic mantras back-to-back.
- **Why it matters for engagement/retention:** Dumping multiple mantras across consecutive turns (Saturn, Rahu, Jupiter) turns an intimate consultation into a transactional checklist, overwhelming the user and decreasing compliance and likelihood of return.
