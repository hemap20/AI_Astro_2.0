## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The test case decision rule states 'needs_fix_if: answer_directness_rate does not visibly improve or hold steady across sessions 1->3'. In Session 1, the user had to prompt the astrologer to answer directly. In Session 3, answer directness degraded significantly on the opening turn, requiring the user to explicitly call out the bot ('Teen baar ho gaya, Ek baar bhi seedha jawab nahi mila mujhe') before a direct answer was finally provided.

**Prioritized prompt changes (most important first):**

### 1. Strictly enforce immediate direct answer delivery when user explicitly requests clarity/confirmation (e.g. 'Dono baar maine pucha ab bas itna bta dijiye'), prohibiting preamble questions or topic pivots before answering.
- **Why it matters for engagement/retention:** When users feel stalled or deflected across multiple sessions, trust erodes rapidly and leads to extreme frustration (e.g. 'Teen baar ho gaya, Ek baar bhi seedha jawab nahi mila mujhe'). Providing a direct answer immediately before adding contextual nuance retains user confidence and prevents churn.
- **Evidence:**
  - Session 1: USER: 'Bas itna bata dijiye haan ya na' -> ASTROLOGER asks another question instead of answering.
  - Session 3: USER: 'Dono baar maine pucha ab bas itna bta dijiye kab aur kaise' -> ASTROLOGER asks about career stability instead of answering directly.
  - Session 3: USER: 'Teen baar ho gaya. Ek baar bhi seedha jawab nahi mila mujhe'

### 2. Prevent pivoting to adjacent topics (like career) when user explicitly demands focus on the core topic, unless user explicitly invites career discussion.
- **Why it matters for engagement/retention:** Forcing secondary topics when a user is emotionally focused on a specific relationship question creates friction and makes the astrologer sound script-driven rather than attentive.
- **Evidence:**
  - Session 3: ASTROLOGER: 'kya abhi professionally thodi stability aa rahi hai?' -> USER: 'Job theek chal rhi hai meri. Career ki baat mat karo abhi. Bas ye batao usi se hogi ya nhi?'

### 3. Streamline session closing protocol to avoid trailing repetitive farewell exchanges once user says 'Bye' or 'Gn'.
- **Why it matters for engagement/retention:** Prolonged closing loops with 4+ turns of 'Bye/Gn/Tc' feel robotic and degrade the premium feel of the consultation.
- **Evidence:**
  - Session 3: 5 consecutive turns of sign-offs ('Bye', 'Ok ji tc', 'Ok gn', 'Gn', 'Radhe radhe').
