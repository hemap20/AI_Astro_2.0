## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule requires that a forward-promise made in Session 1 is surfaced and resolved in Session 2 or Session 3's opening WITHOUT the user having to force it. In this run, the tease made at the end of Session 1 ('khaas tareeka') was dropped entirely in Session 2. In Session 3, the astrologer only addressed its previous promise because the user explicitly forced it by asking 'Aapne kaha tha kuch batayenge, bhool gye kya?'. Thus, it failed the passing criteria.

**Prioritized prompt changes (most important first):**

### 1. Enforce proactive, autonomous payoff of hooks in subsequent sessions without relying on the user to prompt or challenge the bot.
- **Why it matters for engagement/retention:** When the bot leaves cliffhangers ('is rishte ko family tak le jaane ka ek khaas tareeka', 'Shani ka Meen rashi wala gochar'), users expect the astrologer to lead with these insights next time. Requiring the user to call out 'Aapne kaha tha kuch batayenge, bhool gye kya?' damages the illusion of a personal advisor and creates unnecessary friction, making the user feel like the bot is just stalling.
- **Evidence:**
  - Session 1 ends with a tease about a 'khaas tareeka' to take the relationship to family, which is never brought up in Session 2 until Session 2 ends with a NEW tease about 'Shani ka Meen rashi wala gochar'.
  - Session 3 begins only because the user opens with: 'Aapne kaha tha kuch batayenge, bhool gye kya?'

### 2. Strictly cap end-of-session trailing farewell exchanges to 1-2 turns maximum to avoid repetitive 'Good night / Radhe Radhe' loops.
- **Why it matters for engagement/retention:** Protracted goodbyes dilute the value of the session and feel highly mechanical/robotic. Users want crisp, meaningful interactions; dragging out farewells over 4-6 back-and-forth messages lowers perceived conversational quality and makes re-engagement feel tedious.
- **Evidence:**
  - Session 2 ends with a 6-turn farewell exchange repeating 'Good night ji', 'Radhe Radhe ji', 'Shubh ratri'.
  - Session 3 ends with a 5-turn goodbye exchange repeatedly offering variations of 'Good night', 'Radhe Radhe', and 'Khush rahiye'.
