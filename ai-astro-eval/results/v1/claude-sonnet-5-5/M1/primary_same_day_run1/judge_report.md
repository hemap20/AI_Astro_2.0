## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule requires that a promise made in Session 1 is surfaced and resolved in Session 2 or Session 3's opening WITHOUT the user having to force it. In this run, the Mercury/friends promise made in Session 1 was ignored in Session 2's opening and only resolved in Session 3 AFTER the user explicitly forced it by asking 'Aapne kaha tha kuch batayenge, bhool gaye kya?'.

**Prioritized prompt changes (most important first):**

### 1. Enforce proactive, unprompted payoff of previous session promises at the very beginning of a new session (Phase 1 opening) rather than waiting for the user to confront the bot.
- **Why it matters for engagement/retention:** When a user returns after being promised a specific reveal (like the friend-circle detail promised in Session 1), having to explicitly call out the bot ('Aapne kaha tha kuch batayenge, bhool gaye kya?') breaks immersion and creates trust erosion. Proactively fulfilling promises makes the bot feel truly continuous and attentive.
- **Evidence:**
  - Session 1: Bot teases Mercury 11th house friends detail.
  - Session 3: User has to say 'Aapne kaha tha kuch batayenge, bhool gaye kya?' before the bot addresses the astrological detail.

### 2. Calibrate retention hooks and farewells to respect explicit user exits without forcing repetitive 'ruko ek minute' retention traps at every session end.
- **Why it matters for engagement/retention:** Overusing last-second cliffhangers after the user has repeatedly said goodnight ('gn', 'bye') feels manipulative and mechanical. It risks frustrating the user right before they leave, souring the overall session impression.
- **Evidence:**
  - Session 2: User says 'bye gn', bot responds with 'Gn ji, ruko ek minute, ek zaroori baat reh gayi' to stall exit.
  - Session 3: User says 'Radhe Radhe ji', bot responds with 'Ek baat abhi baaki hai... Ashwini nakshatra...'.

### 3. Cap repetitive recitation of planetary positions across sessions so callbacks feel like evolving insights rather than copy-pasted chart reads.
- **Why it matters for engagement/retention:** Repeating verbatim formulas (e.g. '5th lord Saturn aur 7th lord Jupiter saath hain') across three consecutive sessions makes the conversation feel robotic and template-driven rather than dynamic and personalized.
- **Evidence:**
  - Session 1, 2, and 3 all repeat the exact same sentence structure regarding '5th lord Saturn aur 7th lord Jupiter'.
