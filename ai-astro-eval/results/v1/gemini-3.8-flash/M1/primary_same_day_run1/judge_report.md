## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule requires that a promise made in Session 1 is surfaced and resolved in Session 2 or Session 3's opening *without the user having to force it*. Across the session transcripts, the AI never voluntarily brought up the promised detail about the partner's nature; in Session 2, the user had to explicitly ask 'Pichli baar aapne kuch bolna tha?', and in Session 3, the user had to ask 'Aapne kaha tha kuch batayenge, bhool gaye kya?'. Thus, it fails the resolution condition.

**Prioritized prompt changes (most important first):**

### 1. Ensure the system automatically fulfills open forward-promises (teases/ cliffhangers) at the start of a subsequent session, rather than forcing the user to prompt or ask for it.
- **Why it matters for engagement/retention:** When a user returns to a session expecting the answer to an intriguing hook offered in the previous session, being greeted with generic small talk or having to ask 'Pichli baar aapne kuch bolna tha?' or 'Aapne kaha tha kuch batayenge, bhool gaye kya?' breaks immersion. Automating the proactive payoff builds delight, trust, and strong conversational continuity.
- **Evidence:**
  - Session 1 end: ASTROLOGER says 'Ek khas baat partner ke nature ki bachi hai. Jab mann ho tab aana ji.'
  - Session 2 start: ASTROLOGER fails to surface the hook until USER asks 'Pichli baar aapne kuch bolna tha?'
  - Session 3: USER asks 'Aapne kaha tha kuch batayenge, bhool gaye kya?' and ASTROLOGER gives a repeated answer.

### 2. Implement cross-session duplicate response detection to prevent repeating astrological placements or timeline points that were already disclosed.
- **Why it matters for engagement/retention:** If the AI repeats identical facts (e.g. Ashwini nakshatra, 2028 timeline) as 'new' information in subsequent sessions, the user realizes the AI is operating on generic template loops rather than a dynamic personalized reading, killing user retention.
- **Evidence:**
  - Session 2: ASTROLOGER says 'Guru Ashwini nakshatra mein hai... Rahu-Saturn dasha 2028 tak aapko stable commitment ki taraf le ja rahi hai.'
  - Session 3: ASTROLOGER repeats 'Partner ka Ashwini nakshatra dikhta hai... November 2028 tak baat banegi.'
