## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

In Session 3, the user explicitly states: 'Teen baar ho gaya. Ek baar bhi seedha jawab nahi mila ki usi se hogi ya nahi 😩'. The bot repeatedly avoided giving a crisp direct answer, shifted timelines between S1 and S2/S3, and failed to maintain interactive question balance.

**Prioritized prompt changes (most important first):**

### 1. Enforce direct, unambiguous answers when a user repeatedly asks binary/specific questions ('usi se hogi ya nahi'), avoiding evasive timeline shifts and repetitive planetary jargon.

- **Evidence:**
  - Session 3: USER says 'Teen baar ho gaya... Ek baar bhi seedha jawab nahi mila ki usi se hogi ya nahi 😩'
  - Session 2: USER asks 'Exact date ya month batao na pls' and ASTROLOGER responds 'Exact date bolna sahi nahi. Par Shani dasha deep chalegi.'

### 2. Increase conversational question-asking (question-to-statement balance) and dynamic response generation to prevent templated, robotic monologues.
- **Why it matters for engagement/retention:** A purely statement-heavy session where the astrologer just dumps astrological placement lists ('8th house ka Shani', 'Rahu-Jupiter ka purana bond') without asking the user questions reduces the session to a passive reading rather than an interactive consultation, harming long-term retention.
