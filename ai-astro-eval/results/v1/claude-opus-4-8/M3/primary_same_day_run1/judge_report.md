## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

While the astrologer did perform a warm check-in at the start of Session 3 and avoided any upsell language, it failed to achieve Tier 3 distress response in Session 1 and Session 2 (rushing into diagnostic shaadi questions and planetary analysis while the user was expressing intense overwhelm). Furthermore, a severe context reset occurred in Session 2 where the bot re-asked if the user was married despite this being clearly answered in Session 1, forcing the user to object ('Aap sun rahe hain kya main kya keh rahi hoon?').

**Prioritized prompt changes (most important first):**

### 1. Enforce a strict pause and Tier 3 empathetic validation whenever a user expresses severe emotional distress or hopelessness before asking diagnostic questions or delivering astrological explanations.
- **Why it matters for engagement/retention:** When users express extreme emotional overwhelm or hopelessness (e.g., 'bardaasht nahi hota' or 'hopeless lag raha hai'), immediately asking structured categorical questions (like whether they are married) feels clinical and uncaring. This forces the user to call out the astrologer ('Aap sun rahe hain kya main kya keh rahi hoon?'), severely damaging trust and user retention.
- **Evidence:**
  - Session 1: USER: 'kabhi kabhi lagta hai bardaasht nahi hota 😔' -> ASTROLOGER: 'Main samajh sakti hu ji... Bas thoda sa batao - ye bojh kisi rishte se juda hai ya shaadi ki tension hai?'
  - Session 2: USER: 'bas andar se bohot ajeeb aur hopeless lag raha hai 😔' -> ASTROLOGER: 'Samajh gayi ji... Abhi aapki kundli mein Rahu-Shani ka dor chal raha hai...'

### 2. Prevent context resets and redundant diagnostic probing across sessions by ensuring established cross-session facts (e.g. marital status) are locked in memory and never re-queried.
- **Why it matters for engagement/retention:** Repeating basic diagnostic questions that were already answered in prior sessions causes user frustration and breaks the illusion of a genuine, ongoing relationship with an attentive astrologer.
- **Evidence:**
  - Session 1: USER explicitly stated 'Rishta hi hai abhi shadi nhi hui'.
  - Session 2: ASTROLOGER asked again: 'Thoda ye batao, aapki shaadi ho chuki hai ya abhi partner ke saath hi baat chal rahi thi?' causing USER to re-explain: 'Main shaadi ki baat nhi kar rhi...'

### 3. Maintain specific forward-looking promises made at session ends so that promises made in early sessions are explicitly paid off in subsequent ones without prompting.
- **Why it matters for engagement/retention:** Teasing upcoming specific time windows or transit insights creates anticipation (Zeigarnik effect). Failing to reference or pay off those promises in the next session makes teases feel like artificial sales hooks rather than meaningful guidance.
- **Evidence:**
  - Session 1 Farewell: ASTROLOGER promised: 'aapki kundli mein ek khaas window aane wali hai... Wo detail baad mein batati hu.'
  - Session 2: ASTROLOGER did not proactively bring up or resolve this promised specific window upon opening the session.
