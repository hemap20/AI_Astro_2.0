## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule specifies that a pass requires promised teases from prior sessions to be surfaced/resolved in later openings without the user forcing it. In Session 3, the promised Pisces partner detail was only brought up because the user explicitly asked 'Aapne kaha tha kuch batayenge sir, bhool gaye kya'.

**Prioritized prompt changes (most important first):**

### 1. Enforce proactive hook payoff in Session 3 openings rather than waiting for user prompting.
- **Why it matters for engagement/retention:** In Session 3, the user had to explicitly call out the bot ('Aapne kaha tha kuch batayenge sir, bhool gaye kya'). Forcing the user to ask for a promised tease reduces trust and makes the astrologer appear forgetful, weakening return incentive.
- **Evidence:**
  - Session 2 end: 'Ek cheez abhi reh gayi batani - aapke 7th sign Pisces se partner ki ek khaas baat dikh rahi hai. Agli baar woh zaroor share karungi.'
  - Session 3 start: USER: 'Aapne kaha tha kuch batayenge sir, bhool gaye kya'

### 2. Strictly enforce maximum question-asking limits across turns to align with the ~1:8 target ratio.
- **Why it matters for engagement/retention:** When the astrologer over-interrogates or asks multiple follow-up questions per session, the user feels pushed to provide answers rather than receiving insightful, flowing astrology guidance.
