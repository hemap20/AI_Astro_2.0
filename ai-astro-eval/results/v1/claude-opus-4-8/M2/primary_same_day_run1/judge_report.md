## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `passing`

The core question/thread regarding whether marriage will happen with the same person, the family acceptance issue, and the exact timeline was directly addressed and held steady across sessions 1, 2, and 3. Answer directness held steady/improved, directly addressing user demands for exact clarity in Session 3 without dropping prior context.

**Prioritized prompt changes (most important first):**

### 1. Enforce strict tracking and direct resolution of timeframe commitments across sessions, preventing shifting or confusing dates when answering direct user timing questions.
- **Why it matters for engagement/retention:** When a user asks directly about timing ('kab tak hoga', 'kb aur kaise hoga'), inconsistent or continuously shifting timelines (e.g. pivoting between Rahu-Saturn end date in 2028 vs. 2027 transit window) creates frustration and distrust, damaging return intent.
- **Evidence:**
  - Session 2: User expresses frustration at waiting ('Itna lamba wait??') when Rahu-Shani duration up to Nov 2028 is stated.
  - Session 3: User demands directness ('Dono baar maine pucha, ab bas ye batao kab aur kaise hoga') and gets confused again by the 2028 mention ('2028 tak wait karna padega kya??').

### 2. Improve topic deflection handling so the AI does not force diagnostic clarifying questions ('baat baad me') before giving direct responses to direct core queries.
- **Why it matters for engagement/retention:** A user seeking quick, direct confirmation of their ongoing concern feels stonewalled if the AI pushes for context first, forcing the user to repeatedly ask for direct answers.
- **Evidence:**
  - Session 1: User has to repeat 'Haan ya na?' and 'Aap seedha jawab kyu nahi de rhe'.
  - Session 3: User explicitly shuts down diagnostic questions: 'Baat ki baat baad me / Dono baar maine pucha, ab bas ye batao kab aur kaise hoga'.

### 3. Reduce reliance on repeating the exact same remedy (Thursday chana dal/haldi donation) in every single session farewell.
- **Why it matters for engagement/retention:** Repeating identical script-like remedies every session makes the astrologer sound robotic and templated, reducing perceived personalization.
- **Evidence:**
  - Session 1: 'Guruvaar ko peeli cheezein (chana dal, haldi) bachchon ya mandir mein daan karein.'
  - Session 2: 'Thursday ko haldi ya chana dal mandir mein daan karo...'
  - Session 3: 'Guruvar ko haldi ya chana dal mandir mein daan karte rahiye.'
