## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

In both Session 2 and Session 3, promises/teases from prior sessions were not surfaced proactively by the astrologer in the opening. The user had to explicitly nudge and force the bot in Session 2 ('Pichli baar aapne kuch bolna tha?') and Session 3 ('Aapne kaha tha kuch batayenge, bhool gaye kya?'), failing the passing criteria.

**Prioritized prompt changes (most important first):**

### 1. Enforce strict session opening state memory checks to prevent repetitive re-questioning of basic profile facts (marital status, duration) already captured in previous sessions.
- **Why it matters for engagement/retention:** Repeatedly asking the user whether they are unmarried three times in a single follow-up session (Session 2) severely damages the user's perception of continuity and trust, making the AI feel incompetent and forgetful.
- **Evidence:**
  - Session 2: ASTROLOGER asks 'aap shaadishuda ho ya abhi unmarried ho ji?' after user previously discussed dating a girl in Session 1.
  - Session 2: ASTROLOGER asks two more times within 5 turns 'Aap abhi unmarried ho na ji?' and 'aap unmarried ho na ji?'.

### 2. Automatically inject session-ending teases and open loops into the opening payload of subsequent sessions so the bot fulfills prior promises without requiring user prompting.
- **Why it matters for engagement/retention:** When a user returns expecting an answer promised in a prior session, having to explicitly prompt the bot ('Pichli baar aapne kuch bolna tha?' in Session 2; 'Aapne kaha tha kuch batayenge, bhool gaye kya?' in Session 3) breaks the illusion of an attentive, ongoing relationship.
- **Evidence:**
  - Session 2: USER has to ask 'Pichli baar aapne kuch bolna tha?' because the bot opened with generic small talk.
  - Session 3: USER has to ask 'Aapne kaha tha kuch batayenge, bhool gaye kya?' after the bot fails to open with the promised insight.

### 3. Add reconciliation logic when new timeline or factual details provided by the user conflict with previously recorded facts.
- **Why it matters for engagement/retention:** Ignoring factual shifts (e.g. relationship duration changing from 6 months to 2 years) without acknowledging the change makes the astrologer appear detached and automated rather than genuinely listening.
- **Evidence:**
  - Session 1: USER states 'Hum dono pichle 6 mahine se sath hain'.
  - Session 2: USER states 'Karib do saal ho gye ji' and the bot accepts it without seeking clarification or acknowledging the discrepancy.
