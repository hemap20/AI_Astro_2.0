## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule specifies a pass when a promise made in session_1 is surfaced and resolved in session_2 or session_3's opening without the user having to force it. Here, the astrologer completely missed resolving the medical-startup career promise in Session 2 despite the user prompting ('Pichli baar aapne kuch bolna tha na'), and only resolved it in Session 3 after the user explicitly called the bot out ('Bhool gye kya??'). Because the user was forced to ask repeatedly, the run fails the passing condition.

**Prioritized prompt changes (most important first):**

### 1. Enforce proactive pay-off/resolution of previous session cliffhangers at the very beginning of subsequent sessions, rather than generating new teaser hooks on top of unfulfilled ones.
- **Why it matters for engagement/retention:** When an astrologer drops exciting teases ('medical-startup career link') but ignores them in the next session—even after the user explicitly asks 'Pichli baar aapne kuch bolna tha na'—the user loses trust and feels tricked by clickbait tactics. A real user gets frustrated when forced to ask 'Bhool gye kya??' to get an answer.
- **Evidence:**
  - Session 1 tease: 'Waise unke nature aur medical-startup career link par ek bohot interesting cheez dikh rahi hai.'
  - Session 2 failure: User asks 'Pichli baar aapne kuch bolna tha na', but astrologer ignores the career tease and repeats generic Dasha timing.
  - Session 3 failure to proactively resolve: User has to call out 'Aapne kaha tha na kuch aur bhi bataenge / Bhool gye kya??' before the astrologer finally addresses it.

### 2. Prevent repetition of identical Dasha/astrological explanations across sessions when answering different user queries.
- **Why it matters for engagement/retention:** Repeating the exact same phrase ('Rahu-Saturn dasha chal rahi hai ji. 2026 se 2028 ke beech...') across sessions 1, 2, and 3 breaks conversational naturalness and makes the AI sound like a scripted bot, diminishing user willingness to return for genuine guidance.
- **Evidence:**
  - Session 1: 'Abhi Rahu-Saturn dasha chal rahi hai. Clear commitment 2026 se 2028 ke beech aayega.'
  - Session 2: 'Haan ji, Rahu-Shani dasha ki wajah se thoda time lag raha hai. Par 2026 se 2028 ke beech...'
  - Session 3: 'Rahu-Saturn dasha chal rahi hai ji. 2026 se 2028 ke beech baat pakki hogi.'
