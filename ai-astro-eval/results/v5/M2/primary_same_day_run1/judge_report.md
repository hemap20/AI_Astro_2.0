## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule states that the system 'needs_fix' if the answer_directness_rate does not visibly improve or hold steady, or if unresolved threads are dropped. In this run, the answer directness did not improve smoothly; the user had to aggressively demand an answer in Session 3 ('Teen baar ho gaya...') before finally getting a direct confirmation ('Haan ji, bilkul pakka hai'). Furthermore, the unresolved thread from Session 2 (the partner's 'hidden trait' of sports/healing) was completely dropped and never acknowledged or resolved in Session 3, even though a new cliffhanger (Rahu/Ketu secret) was introduced at the end of Session 3.

**Prioritized prompt changes (most important first):**

### 1. Enforce strict memory retrieval of previously prescribed remedies to prevent repeating the exact same remedy as a 'new' suggestion. If a remedy was already given in a prior session, the bot must ask about the user's progress with it rather than introducing it again as a fresh solution.
- **Why it matters for engagement/retention:** In Session 2, the user is given the exact same Saturday Shani remedy they already agreed to try in Session 1, which makes the astrologer look forgetful and repetitive. Users will lose faith in the personalized nature of the consultation if they are repeatedly told to do the same basic task as if it were a new revelation.
- **Evidence:**
  - Session 1: 'Haan ji, bilkul solution hai. Aap Saturday ko Shani dev ka diya jalayein aur mantra japein.'
  - Session 2: 'Saturday ko Shani dev ke aage tel ka diya jalao ji. Om Sham Shanicharaya Namah mantra 108 baar padho.'

### 2. Improve the resolution of cliffhangers and 'hidden secrets' introduced at the end of sessions. If the bot teases a 'hidden trait' or 'secret' to close a session, it must proactively address and resolve that specific tease at the start of the next session.
- **Why it matters for engagement/retention:** The bot ended Session 2 with a cliffhanger about a 'hidden trait' in the partner's chart (sports/healing). However, in Session 3, the bot completely ignored this tease and reverted to a generic greeting, forcing the user to re-initiate the conversation. This breaks narrative continuity and makes retention hooks feel like cheap, manipulative gimmicks rather than genuine astrological insights.
- **Evidence:**
  - Session 2 ending: 'Partner ka ek aur raaz baaki hai... Unki kundli me ek hidden trait hai ji... Woh healing ya sports me active rehte hain ji.'
  - Session 3 opening: 'Hello ji, main Sitara hoon. Bataiye, aaj marriage ko lekar kya pareshani hai?'

### 3. Reduce the rate of deflection and increase directness when users ask binary ('yes/no') or highly specific questions. The bot should validate the question directly before explaining the astrological nuances, rather than repeatedly dodging the question.
- **Why it matters for engagement/retention:** The user became visibly frustrated across all three sessions because they had to ask multiple times for a direct answer to 'will I marry this specific person?'. Repeatedly deflecting direct questions into generic astrological placements (Saturn, Rahu) causes user fatigue and frustration, making them likely to abandon the service.
- **Evidence:**
  - Session 1: 'Aap seedha jawab kyu nhi de rhe'
  - Session 3: 'Teen baar ho gaya, ek baar bhi seedha jawab nahi mila ki usse shadi hogi ya nhi'
