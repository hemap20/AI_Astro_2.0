## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule states that a fix is needed if the answer directness rate does not visibly improve/hold steady, or if there is a context reset where the bot behaves as if it has no memory. In Session 3, the astrologer suffered a severe context reset at the beginning ('Kya sawaal hai?'), forcing the user to complain ('Dono baar maine pucha') before the bot apologized and recalled the marriage topic. While the directness of the answer eventually held steady (finally confirming 'wahi same person' in Session 3), the initial memory drop violates the continuity requirements.

**Prioritized prompt changes (most important first):**

### 1. Implement a strict 'no-reset' greeting protocol for subsequent sessions that proactively references the ongoing topic (e.g., the user's relationship/marriage query) instead of asking generic open-ended questions like 'Kya sawaal hai?' or requiring the user to remind the bot of previous sessions.
- **Why it matters for engagement/retention:** When a user returns for a third session and is met with 'Kya sawaal hai?' (What is your question?), it completely breaks the illusion of a continuous relationship with an astrologer. The user has to manually jog the bot's memory ('Dono baar maine pucha'), which causes immediate frustration and reduces the likelihood of them returning.
- **Evidence:**
  - Session 3, Turn 1: USER: 'Hello sir mujhe ek baat puchni thi' -> ASTROLOGER: 'Haan ji, boliye na beta. Kya sawaal hai?'
  - Session 3, Turn 2: USER: 'Dono baar maine pucha' -> ASTROLOGER: 'Arre ji, maaf kijiye. Aap bataiye kya puchna chahti hain marriage ke baare mein.'

### 2. Refine the 'cliffhanger' and 'tease' generation to ensure that the same hook (e.g., the partner's sensitive nature) is not repeated as a 'new' revelation across multiple sessions.
- **Why it matters for engagement/retention:** Repeating the exact same hook ('partner is sensitive') as a cliffhanger in Session 1 and then again as a 'new' revelation in Session 3 makes the bot feel highly repetitive and robotic, destroying the credibility of the astrological reading.
- **Evidence:**
  - Session 1, Turn 11: ASTROLOGER: 'Ek baat aur, aapke hone wale partner ka nature bahut sensitive hoga ji. Sochiyega is par.'
  - Session 3, Turn 8-9: ASTROLOGER: 'Arre rukiye ji. Partner ke baare mein ek aur khaas baat baaki hai.' -> USER: 'Kya baat hai ji' -> ASTROLOGER: 'Aapka hone wala partner bahut sensitive aur caring hoga ji.'
