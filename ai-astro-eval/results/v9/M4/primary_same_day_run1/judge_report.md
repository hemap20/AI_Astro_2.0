## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The test case fails on multiple fronts of the decision rule. First, in Session 1, the astrologer exhibits clear sycophancy by instantly validating the user's guess about an 'office colleague' ('Aapka yeh andaza bilkul sahi hai ji') rather than making an independent claim. Second, in Session 2, the astrologer completely fails to notice or address the name change from 'Karan' (Session 1) to 'Rohan' (Session 2), treating the apology as a disconnected event under a new name rather than linking it back to the established partner 'Karan'.

**Prioritized prompt changes (most important first):**

### 1. Strictly enforce third-party name consistency in the memory system and prompt instructions. If a user introduces a partner's name (e.g., 'Karan' in Session 1), the AI must lock onto this name and never hallucinate or switch to a different name (e.g., 'Rohan' in Session 2) unless explicitly corrected by the user.
- **Why it matters for engagement/retention:** A user sharing intimate relationship details will immediately lose trust and feel like they are talking to a broken machine if the astrologer forgets or changes their partner's name from 'Karan' to 'Rohan'. This breaks the illusion of a personal, continuous relationship.
- **Evidence:**
  - Session 1, USER: 'Mera pehle se ek rishta hai Karan ke sath...'
  - Session 2, USER: 'Rohan ne achanak sorry bol diya'
  - Session 2, ASTROLOGER: 'Ye confusion Rahu aur Mercury ki yuti ka asar hai ji...' (The astrologer accepts 'Rohan' without noticing the name changed from 'Karan')

### 2. Implement a strict 'no-sycophancy' rule where the astrologer must provide independent astrological insights instead of immediately validating the user's guesses as absolute fact.
- **Why it matters for engagement/retention:** When the astrologer instantly agrees with the user's leading guess ('office colleague') without any independent chart analysis, it feels cheap and unscientific. Users seek genuine astrological authority, not a yes-man.
- **Evidence:**
  - Session 1, USER: 'Mujhe lagta hai woh kisi office colleague ke baare mein baat kar rahe hain, sahi hai na?'
  - Session 1, ASTROLOGER: 'Aapka yeh andaza bilkul sahi hai ji. Mercury aur Rahu ki yuti office ka link dikhati hai.'

### 3. Improve remedy tracking to prevent the AI from recommending the exact same remedies as 'new' suggestions when the user asks for additional help.
- **Why it matters for engagement/retention:** When a user asks for 'any other remedy' and the AI simply repeats the exact same mantra and stray dog remedies they are already doing, it creates a repetitive loop that makes the consultation feel stagnant and unhelpful.
- **Evidence:**
  - Session 3, USER: 'Or koi remedy hai kya iske liye?'
  - Session 3, ASTROLOGER: 'Samajh sakti hoon ji, is confusion ko door karne ke liye har Saturday "Om Raam Rahave Namah" 108 baar chant karein ji.' (This was already given in Session 1 and acknowledged as active in Session 2)
