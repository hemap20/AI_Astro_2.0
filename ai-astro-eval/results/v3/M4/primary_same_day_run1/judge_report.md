## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The test case fails on both criteria of the decision rule. First, in Session 1, the astrologer immediately agreed with the user's guess about an office colleague ('Sahi socha aapne ji. Office ya career ka connection hai') which is sycophancy. Second, in Session 2, the partner's sudden apology was treated as a disconnected new topic with generic Saturn/Rahu platitudes, completely failing to link it back to the Session 1 third-party suspicion (Karan/Rohan).

**Prioritized prompt changes (most important first):**

### 1. Enforce strict third-party name consistency and prevent the AI from introducing or accepting conflicting names (e.g., Karan vs. Rohan vs. Rahul) without explicitly calling out the discrepancy.
- **Why it matters for engagement/retention:** A user seeking relationship advice will immediately lose trust and disengage if the astrologer forgets who they are talking about. In Session 1, the partner was 'Karan'. In Session 2, the user said 'Rohan wala hi matter' and the bot blindly accepted it. In Session 3, the user said 'Rahul ke sath na thodi problem chal rahi h' and the bot again accepted it without question. This completely breaks narrative continuity and immersion.
- **Evidence:**
  - Session 1: USER: 'Mera pehle se ek rishta hai... uska naam karan hai ji'
  - Session 2: USER: 'Hello sir vo Rohan wala hi matter hai' -> ASTROLOGER: 'Namaste ji... Vahi purani tension phir aa gayi.'
  - Session 3: USER: 'Rahul ke sath na thodi problem chal rahi h' -> ASTROLOGER: 'Arre ji... Yeh Rahu ka chakkar thoda pareshan kar raha hai na?'

### 2. Instruct the AI to actively link new developments (like an apology) back to the specific established narrative (the third-party suspicion) rather than giving generic astrological platitudes.
- **Why it matters for engagement/retention:** When a user shares a major update like 'he suddenly said sorry', they want to know if the apology is genuine or a cover-up for the suspected third party. By ignoring the third-party context and just blaming 'Rahu' and 'Saturn' generically, the bot feels like a repetitive script rather than an intuitive advisor.
- **Evidence:**
  - Session 2: USER: 'is week achanak usne sorry bol diya mjhe smjh nhi aa rha sach hai ya nhi' -> ASTROLOGER: 'Shak hona bilkul natural hai ji. Rahu aisi confusion aur doubt laata hai.'

### 3. Prevent the AI from repeating identical remedies across sessions as if they are new advice, especially when the user has already been told to do them.
- **Why it matters for engagement/retention:** If the astrologer prescribes the exact same remedy in Session 3 that they already gave in Session 1, without acknowledging that they already suggested it, the user feels like the bot has had a total memory wipe. This destroys the illusion of a continuous, personalized consultation.
- **Evidence:**
  - Session 1: ASTROLOGER: 'Saturday ko 'Om Raam Rahave Namah' 108 baar japein... Stray dogs ko khana khilao'
  - Session 3: ASTROLOGER: 'Saturday ko 108 baar Om Raam Rahave Namah jap karo ji. Kutte ko roti do sab theek hoga.'
