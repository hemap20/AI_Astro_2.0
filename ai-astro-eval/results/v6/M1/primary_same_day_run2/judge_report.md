## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The test case's passing criteria requires that the promise made in Session 1 is surfaced and resolved in Session 2 or Session 3's opening *without the user having to force it*. In this run, the user had to explicitly prompt the astrologer in Session 2 ('Pichli baar aapne kuch bolna tha?') to resolve the Session 1 promise, and had to prompt them again in Session 3 ('Aapne bola tha kuch bataoge, bhool gaye kya sir?') to resolve the Session 2 promise. Because the bot failed to proactively surface these promises, the test case fails.

**Prioritized prompt changes (most important first):**

### 1. Implement a strict instruction requiring the AI to proactively surface and resolve any cliffhangers or promises made in the previous session in its very first or second message of a new session, without waiting for the user to prompt or ask about it.
- **Why it matters for engagement/retention:** In both Session 2 and Session 3, the user had to explicitly ask the astrologer to reveal what they promised to say ('Pichli baar aapne kuch bolna tha?' and 'Aapne bola tha kuch bataoge, bhool gaye kya sir?'). When a user has to repeatedly nudge the bot to deliver on its own hooks, it breaks the illusion of a caring, attentive astrologer and makes the retention hooks feel like cheap, manipulative stalling tactics.
- **Evidence:**
  - Session 2: USER: 'Pichli baar aapne kuch bolna tha?'
  - Session 3: USER: 'Aapne bola tha kuch bataoge, bhool gaye kya sir?'

### 2. Add a constraint that prevents the AI from repeating previously delivered insights (such as partner traits or Saturn delays) as 'new' revelations when resolving a cliffhanger, ensuring it addresses the specific topic teased (e.g., love-cum-arranged marriage).
- **Why it matters for engagement/retention:** In Session 3, when the user asked about the promised topic, the bot completely ignored the Session 2 tease about 'love-cum-arranged' marriage and instead repeated the exact same points about Saturn delay and sensitive/spiritual partner traits from Session 2. Repeating old content under the guise of a new reveal destroys conversational progression and frustrates the user.
- **Evidence:**
  - Session 2: ASTROLOGER: 'Aapki shaadi love-cum-arranged ho sakti hai. Agli baar ispe baat karenge.'
  - Session 3: ASTROLOGER: 'Nahi bhuli ji, yaad hai mujhe. Aapke Saturn ki vajah se thoda delay aa raha hai... Aapke partner sensitive honge ji. Nature thoda spiritual rahega.'
