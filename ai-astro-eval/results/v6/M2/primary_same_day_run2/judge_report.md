## Cross-Session Synthesis (all 3 sessions)

**Decision rule verdict:** `needs_fix`

The decision rule states that the system needs a fix if the Session-1 unresolved thread is dropped (not just re-answered, but never acknowledged) once a new thread is introduced. In Session 1, the astrologer teased a forward-promise: 'Ek baat aur batani baaki hai ji, partner ka nature kaisa hoga.' In Session 2, the astrologer briefly mentioned the partner is 'sensitive' only as a parting cliffhanger, and in Session 3, this thread about the partner's nature was completely dropped and never resolved or elaborated upon, despite the user asking 'kb aur kaise' and 'Vhi same person ke sath hoga na?'.

**Prioritized prompt changes (most important first):**

### 1. Enforce strict context-retention rules to prevent the bot from greeting returning users as strangers. If a user has had prior sessions, the bot must not use generic introductions like 'Main Sitara hoon, aapki astrologer. Boliye, marriage ke baare mein kya janna chahte hain?' but must instead acknowledge the ongoing conversation and the specific context (e.g., the Saturday remedy).
- **Why it matters for engagement/retention:** A user who has spent multiple sessions discussing their deepest relationship anxieties will feel completely disconnected and frustrated if the astrologer introduces themselves from scratch in Session 3. This breaks the illusion of a real relationship and severely damages retention.
- **Evidence:**
  - Session 3, Turn 2: ASTROLOGER: 'Hello ji! Main Sitara hoon, aapki astrologer. Boliye, marriage ke baare mein kya janna chahte hain?'
  - Session 3, Turn 3: USER: 'Dono baar maine pucha'

### 2. Implement a mandatory check to verify if a user has completed a previously prescribed remedy before suggesting new ones, and explicitly follow up on the outcome of the previous remedy.
- **Why it matters for engagement/retention:** In Session 2, the user explicitly promised to go to the temple on Saturday and report back. In Session 3, the astrologer completely ignored this pending feedback loop and immediately jumped to a new remedy (neembu tel ka diya). This makes the remedies feel like generic, automated scripts rather than personalized spiritual guidance.
- **Evidence:**
  - Session 2, Turn 12: USER: 'Saturday ko jaakar batati hu apko'
  - Session 3, Turn 10: ASTROLOGER: 'Sab theek hoga ji. Shanivar ko neembu tel ka diya jalayein.'

### 3. Reduce repetitive astrological explanations (such as '5th and 7th house connection' and '2026 to 2028 yog') across sessions. Instruct the bot to build upon previous explanations with deeper, new insights rather than repeating the exact same phrases.
- **Why it matters for engagement/retention:** When the astrologer repeats the exact same astrological jargon ('5th aur 7th ka strong link') across three sessions, the user realizes the bot has a limited script. Providing deeper, progressive details keeps the user curious and coming back for more.
- **Evidence:**
  - Session 1, Turn 15: ASTROLOGER: 'Kundli mein 5th aur 7th ka strong link hai.'
  - Session 2, Turn 10: ASTROLOGER: 'Kundli mein 5th aur 7th ka strong link hai ji.'
  - Session 3, Turn 6: ASTROLOGER: '5th aur 7th house ka strong connection hai.'
